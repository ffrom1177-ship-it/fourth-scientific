# الرابع العلمي – دليلك الدراسي

تطبيق ويب عربي (PWA) يعمل على الهاتف ويمكن تثبيته من Chrome.

## الملفات
- `index.html`: التطبيق.
- `manifest.webmanifest`: إعدادات التثبيت.
- `sw.js`: التخزين المؤقت للعمل دون اتصال بعد أول زيارة.
- `icon.svg`: أيقونة التطبيق.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً في GitHub.
2. ارفع **كل الملفات الموجودة داخل المجلد** إلى جذر المستودع.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch ثم `main` و`/(root)` ثم Save.
5. افتح رابط GitHub Pages من Chrome.
6. من قائمة Chrome اختر Install app أو Add to Home screen.

## ملاحظة المحتوى
هذا إصدار أولي يضم المواد وروابط مصادر الكتب والملازم، مع أمثلة وأسئلة تدريبية أصلية. الروابط الخارجية تفتح مواقع المصادر ولا تعني أن التطبيق يملك حقوق ملفاتها. أضف ملفاتك أو روابطها الموثوقة لاحقاً لكل فصل.
